# ProPresenter Familiarity Targets

The objective is not a pixel-for-pixel copy. The objective is transferable operator skill.

## Preserve closely

- left-side library and playlist mental model
- playlist-item selection flow
- central grouped slide thumbnail view
- clicking a slide sends it live
- visible distinction between selected and live
- next / previous navigation
- layer-aware clear controls
- Audience and Stage as explicit output concepts
- media kept conceptually separate from presentation slides
- familiar keyboard shortcuts where practical

## Intentionally allowed to differ

- application branding and icons
- exact visual styling
- internals and file formats
- Kids Church-specific interactive tools
- custom web-tool workflow
- optional integrated media acquisition
- CrowdLight integration
- future training mode

## Training rule

Where a proposed simplification would make KidsChurch Presenter easier but teach a materially different operating habit from ProPresenter, prefer the ProPresenter-familiar behaviour unless there is a strong Kids Church reason not to.
